# Changelog

Все значимые изменения Obsidian TaskMaster документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
проект следует [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Пост-задачи — у задачи может быть до 20 пунктов о том, что сделать после неё (до 200 символов каждый); они редактируются в новом блоке формы «После выполнения». На карточке маркер `↪ N` показывает число ещё не заведённых пунктов, подсказка при наведении перечисляет их. Когда задача попадает в «Завершённые» из другой группы — кнопкой ☑ или перетаскиванием, — каждый незаведённый пункт становится новой задачей в конце бэклога той же доски («Зачем» = «После: » + «Что» родителя, приоритет по умолчанию, статус «Новая»), а уведомление Obsidian сообщает, сколько задач заведено, с текущим названием бэклога и пометкой, если он скрыт. Кнопка «→ в бэклог» помечает пункт для досрочного заведения при сохранении. Отмена ☑ удаляет задачи, заведённые этим завершением, и возвращает их пункты в «не заведено». Перестановка внутри «Завершённых» и выбор статуса «Завершена» в форме ничего не заводят; у задачи в «Завершённых» список только для чтения. Версия схемы данных обновлена до 9
- Настройка групп — переименование групп и настройка их порядка для каждой доски через попап настроек доски. Пустое название означает дефолтное локализованное, поэтому очистка поля и есть сброс; длина названия ограничена 40 символами. Стрелки перемещают группу вверх или вниз: видимая группа меняется местами с ближайшей видимой соседкой, перешагивая скрытые, а скрытая переходит на соседнюю позицию и сохраняет своё место в списке настроек. Версия схемы данных обновлена до 8
- Видимость секции Notes — скрыть или показать секцию Notes для каждой доски через попап настроек доски. Содержимое заметок сохраняется при скрытии и восстанавливается при показе; состояние collapse/expand также сохраняется. Версия схемы данных обновлена до 7
- Динамический лейаут — настройка ширины каждой группы для доски: полная ширина (100%) или половина (50%). Группы с половинной шириной автоматически выстраиваются парами; одиночная группа с половинной шириной растягивается на полную. На узких экранах (<600px) все группы занимают полную ширину
- Настройки видимости групп — скрывать или показывать отдельные группы задач для каждой доски через попап настроек доски. Задачи в скрытых группах сохраняются; автоматизации (завершение задач, переходы статусов) работают независимо от видимости. Хотя бы одна группа должна оставаться видимой
- Секция «Заметки» под группой «Завершённые» — сворачиваемое текстовое поле для быстрых заметок, ссылок и идей без создания полноценной задачи. Привязана к доске, автосохранение с debounce
- Новый статус задачи «Звонок» (📞) для визуального отделения созвонов и встреч от рабочих задач при планировании дня
- Кнопка быстрого закрытия задачи (☑) на каждой карточке — один клик перемещает задачу в начало группы «Завершённые» со статусом `completed`, без открытия модалки редактирования
- Отмена быстрого закрытия через toast-уведомление (7 секунд), единая очередь с отменой удаления (максимум 3 toast'а)
- Компактный режим отображения карточек для работы с большим количеством задач
- Интернационализация (i18n) с поддержкой английского и русского языков

### Changed
- Тип toast теперь является discriminated union (`delete` | `complete`) для type-safe обработки
- Обновлена структура данных настроек — добавлены поля `language` и `cardView`
- Версия схемы данных обновлена до `3` с автоматической миграцией
- Версия схемы данных обновлена до `4` с автоматической миграцией (добавляет `hiddenGroups: []` к существующим доскам)
- Версия схемы данных обновлена до `5` с автоматической миграцией (добавляет `fullWidth` каждой группе с дефолтами, сохраняющими текущий лейаут)

### Fixed
- Исправлено наложение даты дедлайна на кнопки действий в обычном режиме карточки
- Исправлено растягивание групп длинными названиями задач

## [0.1.0] - 2026-02-14

### Added
- Начальный релиз с визуальной доской задач и 6 группами
- Структурированные карточки задач в стиле SMART (Что, Зачем, Кто, Когда, Приоритет, Статус)
- Drag-and-drop перемещение задач между группами
- WIP-лимиты для групп с визуальной индикацией превышения
- Отмена удаления задач через toast-уведомления (7 секунд)
- Автоматические переходы статусов при перемещении между группами
- Автоочистка завершённых задач по настраиваемому сроку хранения
- Поддержка нескольких досок с переключением через селектор
- Индикация просрочки (красная рамка карточки при превышении дедлайна)
- Сворачиваемые группы (Backlog и Completed)
