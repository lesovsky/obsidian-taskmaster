# Obsidian TaskMaster — сценарии тестирования

Документ для ручного тестирования плагина. Каждый сценарий содержит шаги и ожидаемый результат.

---

## 1. Установка и первый запуск

### 1.1 Установка плагина

**Шаги:**
1. Скопировать `main.js`, `manifest.json`, `styles.css` в `.obsidian/plugins/obsidian-taskmaster/`
2. В Obsidian → Настройки → Community plugins → включить TaskMaster

**Ожидаемый результат:**
- Плагин появляется в списке установленных
- В левой боковой панели (ribbon) появляется иконка доски

### 1.2 Первое открытие доски

**Шаги:**
1. Нажать на иконку TaskMaster в ribbon

**Ожидаемый результат:**
- Открывается новая вкладка (в центральной области, как обычная заметка)
- Видна доска «Моя доска» с 6 группами
- Бэклог — свёрнут, видна стрелка ▶ и счётчик (0)
- Фокус и В работе — рядом в одной строке
- Орг. намерения — на всю ширину
- Делегировано — на всю ширину
- Завершённые — свёрнуты внизу
- Все группы пустые, в каждой — текст-подсказка

### 1.3 Повторное открытие

**Шаги:**
1. Доска уже открыта
2. Нажать на иконку TaskMaster в ribbon ещё раз

**Ожидаемый результат:**
- Новая вкладка **не создаётся** — переключение на существующую

### 1.4 Открытие через Command Palette

**Шаги:**
1. Закрыть вкладку с доской
2. Ctrl+P → ввести «TaskMaster» → выбрать «TaskMaster: Open board»

**Ожидаемый результат:**
- Доска открывается в новой вкладке

## 2. Пустые состояния (Empty States)

### 2.1 Тексты подсказок

**Шаги:**
1. Открыть доску
2. Развернуть Бэклог (нажать на заголовок)
3. Развернуть Завершённые
4. Проверить текст в каждой пустой группе

**Ожидаемый результат:**

| Группа | Текст |
|--------|-------|
| Бэклог | «Задачи на будущее. Складывайте сюда всё, что появляется на горизонте, но пока не готово к работе» |
| Фокус | «Что сейчас требует вашего внимания? Перетащите сюда задачи, которые нельзя упускать из виду» |
| В работе | «Чем вы занимаетесь прямо сейчас? Добавьте задачи, над которыми работаете лично» |
| Орг. намерения | «Что запланировано на эту неделю? Разместите здесь цели, которые хотите закрыть до конца недели» |
| Делегировано | «Что вы поручили другим? Добавьте задачи, переданные коллегам, чтобы не забыть проверить их статус» |
| Завершённые | «Пока пусто — завершённые задачи будут появляться здесь» |

## 3. Создание задач

### 3.1 Создание задачи в рабочей группе

**Шаги:**
1. Нажать «+» в группе «Фокус»
2. В модальном окне проверить заголовок
3. Заполнить поле «Что» — «Подготовить отчёт для совета директоров»
4. Заполнить «Зачем» — «Нужен для бюджета Q2»
5. Заполнить «Кто» — «Иванов А.»
6. Выбрать дедлайн — любая будущая дата
7. Нажать «Сохранить»

**Ожидаемый результат:**
- Модальное окно с заголовком «Новая задача»
- Кнопка «Сохранить» неактивна пока поле «Что» пустое
- После сохранения — карточка появляется в группе «Фокус»
- Карточка отображает: иконки приоритета (🟡) и статуса (🔵 В работе), дедлайн, текст задачи, исполнителя (👤 Иванов А.)
- Статус автоматически «В работе» (не «Новая»)
- Текст-подсказка пропадает

### 3.2 Создание задачи в бэклоге

**Шаги:**
1. Развернуть Бэклог
2. Нажать «+»
3. Заполнить только поле «Что» — «Изучить конкурентов»
4. Сохранить

**Ожидаемый результат:**
- Карточка в бэклоге
- Статус — 🆕 Новая (не «В работе»)
- Приоритет — 🟡 средний (по умолчанию)
- Нет дедлайна, нет исполнителя на карточке

### 3.3 Создание задачи — обязательность поля «Что»

**Шаги:**
1. Нажать «+» в любой группе
2. Оставить поле «Что» пустым
3. Попробовать нажать «Сохранить»

**Ожидаемый результат:**
- Кнопка «Сохранить» неактивна (disabled)
- Задача не создаётся

### 3.4 Создание нескольких задач подряд

**Шаги:**
1. Создать 3 задачи в группе «В работе»

**Ожидаемый результат:**
- Все 3 карточки появляются в порядке создания (последняя внизу)
- Счётчик в заголовке группы обновляется (3)

## 4. Редактирование задач

### 4.1 Открытие карточки для редактирования

**Шаги:**
1. Кликнуть по карточке задачи

**Ожидаемый результат:**
- Модальное окно с заголовком «Редактирование задачи»
- Все поля предзаполнены текущими данными задачи
- Внизу формы — метаданные: дата создания (и дата завершения, если есть)
- Есть кнопка «Удалить» (красная)
- Есть выпадающее поле «Статус» (в отличие от создания, где статуса нет)

### 4.2 Изменение полей

**Шаги:**
1. Открыть карточку
2. Изменить поле «Что» — добавить текст
3. Изменить приоритет на «Высокий»
4. Сохранить

**Ожидаемый результат:**
- Карточка обновилась: новый текст, иконка приоритета сменилась на 🔴
- Позиция карточки в группе не изменилась

### 4.3 Изменение статуса вручную

**Шаги:**
1. Открыть карточку со статусом «В работе»
2. Сменить статус на «Ожидает»
3. Сохранить

**Ожидаемый результат:**
- Иконка статуса на карточке — ⏳
- Карточка остаётся в той же группе

## 5. Удаление задач

### 5.1 Удаление с карточки (hover)

**Шаги:**
1. Навести мышь на карточку
2. Нажать кнопку «×» в правом верхнем углу

**Ожидаемый результат:**
- Карточка исчезает из группы
- Внизу экрана появляется toast: «"Название задачи" удалена (7с)» с кнопкой «Отменить»
- Таймер обратного отсчёта: 7, 6, 5...
- Через 7 секунд toast исчезает

### 5.2 Удаление из модального окна

**Шаги:**
1. Кликнуть по карточке → открывается модалка
2. Нажать кнопку «Удалить» внизу формы

**Ожидаемый результат:**
- Модальное окно закрывается
- Карточка исчезает, появляется toast

### 5.3 Отмена удаления (Undo)

**Шаги:**
1. Удалить задачу
2. Пока toast видим — нажать «Отменить»

**Ожидаемый результат:**
- Карточка возвращается в ту же группу на **ту же позицию**
- Toast исчезает

### 5.4 Таймер истёк — окончательное удаление

**Шаги:**
1. Удалить задачу
2. Подождать 7 секунд, не нажимая «Отменить»

**Ожидаемый результат:**
- Toast исчезает
- Задача удалена окончательно (не появляется при перезагрузке плагина)

### 5.5 Стакинг toast'ов (макс. 3)

**Шаги:**
1. Быстро удалить 4 задачи подряд (до истечения первого таймера)

**Ожидаемый результат:**
- Одновременно видно максимум 3 toast'а
- При удалении 4-й задачи — самый старый toast исчезает (его задача удаляется окончательно)
- Новый toast появляется

### 5.6 Длинное название в toast

**Шаги:**
1. Создать задачу с названием длиннее 40 символов
2. Удалить её

**Ожидаемый результат:**
- В toast название обрезано до 40 символов с многоточием «…»

## 6. Drag-and-drop

### 6.1 Перемещение внутри одной группы

**Шаги:**
1. Создать 3 задачи в группе «В работе»
2. Перетащить третью задачу на первое место

**Ожидаемый результат:**
- Задача переместилась на первую позицию
- Порядок сохранён после перезагрузки плагина
- При перетаскивании видна «тень» карточки (ghost)

### 6.2 Перемещение между рабочими группами

**Шаги:**
1. Создать задачу в «Фокус»
2. Перетащить её в «Делегировано»

**Ожидаемый результат:**
- Карточка появляется в «Делегировано»
- Счётчики обеих групп обновились
- Статус задачи **не изменился** (остался прежний)

### 6.3 Из бэклога в рабочую группу (авто-переход статуса)

**Шаги:**
1. Развернуть Бэклог
2. Создать задачу в бэклоге (она получит статус «Новая» 🆕)
3. Перетащить её в «В работе»

**Ожидаемый результат:**
- Карточка в группе «В работе»
- Статус автоматически изменился на «В работе» 🔵
- Счётчик бэклога уменьшился, «В работе» увеличился

### 6.4 Перемещение в «Завершённые» (авто-завершение)

**Шаги:**
1. Развернуть «Завершённые»
2. Перетащить любую задачу из рабочей группы в «Завершённые»

**Ожидаемый результат:**
- Карточка в группе «Завершённые»
- Статус автоматически → ✅ Завершена
- На карточке — иконка ✅
- Если у задачи были незаведённые пост-задачи, в конце бэклога появляются задачи из них и показывается уведомление (см. раздел 21). Перестановка внутри «Завершённых» ничего не заводит

### 6.5 Возврат из «Завершённых» на доску

**Шаги:**
1. Перетащить задачу из «Завершённых» обратно в рабочую группу

**Ожидаемый результат:**
- Карточка в рабочей группе
- Статус автоматически → 🔵 В работе
- Дата завершения очищена

### 6.6 Перемещение в пустую группу

**Шаги:**
1. Убедиться, что группа «Орг. намерения» пуста (видна подсказка)
2. Перетащить задачу из другой группы в «Орг. намерения»

**Ожидаемый результат:**
- Задача появляется в «Орг. намерениях»
- Текст-подсказка исчезает

## 7. Сворачивание групп

### 7.1 Свернуть/развернуть Бэклог

**Шаги:**
1. Нажать на заголовок «Бэклог»

**Ожидаемый результат:**
- Группа разворачивается, стрелка поворачивается ▼
- Видны карточки (или подсказка, если пусто)

### 7.2 Состояние свёрнутости сохраняется

**Шаги:**
1. Развернуть Бэклог
2. Перезагрузить плагин (Ctrl+P → «Reload app without saving»)
3. Открыть доску

**Ожидаемый результат:**
- Бэклог остаётся развёрнутым

## 8. WIP-лимиты

### 8.1 Установка WIP-лимита

**Шаги:**
1. В группе «В работе» нажать кнопку ⚙ в заголовке
2. В popup ввести WIP-лимит: 3
3. Нажать «Сохранить»

**Ожидаемый результат:**
- Popup закрывается
- В заголовке группы отображается счётчик в формате «(N/3)», где N — текущее количество задач

### 8.2 Превышение WIP-лимита

**Шаги:**
1. Установить WIP-лимит = 2 для группы
2. Добавить 3 задачи в эту группу

**Ожидаемый результат:**
- Счётчик: (3/2) — красным цветом, жирный
- Задачи **можно** добавлять и перемещать (лимит мягкий)
- Визуальное предупреждение — красный индикатор

### 8.3 Снятие WIP-лимита

**Шаги:**
1. Открыть настройки группы (⚙)
2. Очистить поле WIP-лимита (оставить пустым)
3. Сохранить

**Ожидаемый результат:**
- Счётчик в формате «(N)» без дроби
- Красная индикация исчезла

### 8.4 WIP-лимит для сворачиваемых групп

**Шаги:**
1. Открыть настройки Бэклога (⚙ в заголовке при развёрнутом бэклоге)
2. Установить WIP-лимит
3. Сохранить

**Ожидаемый результат:**
- Лимит отображается в заголовке даже когда группа свёрнута

## 9. Настройки группы «Завершённые»

### 9.1 Изменение срока хранения

**Шаги:**
1. Развернуть «Завершённые»
2. Нажать ⚙ в заголовке
3. В поле «Хранение завершённых (дни)» ввести 7
4. Сохранить

**Ожидаемый результат:**
- Popup закрывается
- Настройка сохранена (задачи старше 7 дней будут автоматически удалены при перезагрузке или через час)

### 9.2 Поле «Хранение» видно только для «Завершённых»

**Шаги:**
1. Открыть настройки любой рабочей группы (⚙)

**Ожидаемый результат:**
- Поле «Хранение завершённых (дни)» **не отображается** — только WIP-лимит

## 10. Управление досками

### 10.1 Создание новой доски

**Шаги:**
1. Нажать кнопку «+» рядом с селектором доски

**Ожидаемый результат:**
- Создаётся доска «Новая доска»
- Автоматическое переключение на новую доску
- Все 6 групп пустые с подсказками
- Старая доска доступна через селектор

### 10.2 Переключение между досками

**Шаги:**
1. Создать 2 доски с задачами в каждой
2. Переключить доску через селектор (выпадающий список)

**Ожидаемый результат:**
- Отображается выбранная доска со своими задачами
- Задачи одной доски не смешиваются с другой

### 10.3 Настройки доски — переименование

**Шаги:**
1. Нажать ⚙ рядом с селектором доски
2. Изменить название на «Проект Alpha»
3. Добавить подзаголовок «Разработка MVP»
4. Сохранить

**Ожидаемый результат:**
- Popup закрывается
- В селекторе отображается новое название
- Под заголовком — подзаголовок «Разработка MVP»

### 10.4 Настройки доски — пустое название

**Шаги:**
1. Открыть настройки доски
2. Очистить поле «Название»
3. Попробовать сохранить

**Ожидаемый результат:**
- Кнопка «Сохранить» неактивна — название обязательное

### 10.5 Удаление доски — подтверждение

**Шаги:**
1. Убедиться, что есть 2+ доски
2. Открыть настройки доски (⚙)
3. Нажать «Удалить доску»

**Ожидаемый результат:**
- Появляется подтверждение: «Удалить доску и все задачи?»
- Кнопки «Нет» и «Да, удалить»
- «Нет» — отменяет, ничего не происходит

### 10.6 Удаление доски — подтверждённое

**Шаги:**
1. Нажать «Да, удалить»

**Ожидаемый результат:**
- Доска удалена
- Переключение на оставшуюся доску
- Задачи удалённой доски больше не существуют

### 10.7 Нельзя удалить последнюю доску

**Шаги:**
1. Убедиться, что осталась только одна доска
2. Открыть настройки доски

**Ожидаемый результат:**
- Кнопка «Удалить доску» **отсутствует**

### 10.8 Подзаголовок доски — скрытие

**Шаги:**
1. Открыть настройки доски
2. Очистить подзаголовок
3. Сохранить

**Ожидаемый результат:**
- Подзаголовок не отображается, не занимает место

## 11. Индикация просрочки

### 11.1 Просроченный дедлайн

**Шаги:**
1. Создать задачу с дедлайном в прошлом (например, вчера)

**Ожидаемый результат:**
- Карточка имеет красную рамку (border)
- Дата дедлайна отображается красным цветом

### 11.2 Просрочка не действует на завершённые

**Шаги:**
1. Создать задачу с прошедшим дедлайном
2. Перетащить её в «Завершённые»

**Ожидаемый результат:**
- Красная рамка **исчезает** (задача завершена — просрочка неактуальна)

### 11.3 Задача без дедлайна

**Шаги:**
1. Создать задачу без указания дедлайна

**Ожидаемый результат:**
- Нет дедлайна на карточке
- Нет красной рамки

## 14. Глобальные настройки плагина

## 21. Пост-задачи

### 21.1 Добавление пунктов в форме

**Шаги:**
1. Открыть задачу «Выпустить релиз» с дедлайном
2. В блоке «После выполнения» (между «Зачем» и «Кто / Когда») нажать «+ Добавить пункт», ввести «Провести ретро»
3. Нажать Enter, во втором поле ввести «Разослать release notes»
4. Сохранить и снова открыть задачу

**Ожидаемый результат:**
- Enter добавил пустой пункт сразу после текущего и поставил в него фокус
- На карточке слева от дедлайна появился `↪ 2`, при наведении — оба пункта, каждый с новой строки
- В форме оба пункта на месте, после перезапуска Obsidian тоже

### 21.2 Лимиты и пустые пункты

**Шаги:**
1. Добавить пункт из одних пробелов и пункт длиннее 200 символов
2. Добавлять пункты, пока их не станет 20
3. Сохранить

**Ожидаемый результат:**
- Поле пункта не принимает больше 200 символов
- На 20 пунктах кнопка «+ Добавить пункт» неактивна, Enter новый пункт не добавляет
- Пустой пункт после сохранения пропал

### 21.3 Маркер в компактном и мультиколоночном режимах

**Шаги:**
1. Включить Card view = Compact, затем Card layout = Multi
2. Посмотреть на карточки с пунктами — с дедлайном и без него
3. Вернуть Card view = Default (Card layout = Multi) и посмотреть на карточку с пунктами и дедлайном в полноширинной группе (4 колонки)

**Ожидаемый результат:**
- В компактном режиме `↪N` стоит перед дедлайном или на его месте
- В 4 колонках маркер не наезжает на кнопки ☑ и ✕, текст задачи обрезается с многоточием
- Шаг 3: маркер `↪ N` вплотную слева от даты, дата при нехватке места сжимается с многоточием и не заезжает под ☑ и ✕; полная дата видна в подсказке при наведении
- У задачи без пунктов или со всеми заведёнными пунктами маркера нет

### 21.4 Завершение кнопкой ☑

**Шаги:**
1. Нажать ☑ на задаче с двумя незаведёнными пунктами
2. Развернуть бэклог, открыть одну из новых задач, затем открыть завершённую задачу

**Ожидаемый результат:**
- Появился обычный toast завершения с «Отменить» и уведомление Obsidian «Заведено задач в «Бэклог»: 2»
- В конце бэклога две задачи в порядке пунктов. «Зачем» — «После: Выпустить релиз», статус «Новая», приоритет по умолчанию, «Кто» и «Когда» пусты
- В форме завершённой задачи оба пункта отмечены «✓ заведено», маркера на карточке нет
- Бэклог сам не развернулся
- ☑ на задаче без незаведённых пунктов завершает её как раньше, без уведомления

### 21.5 Отмена ☑

**Шаги:**
1. У задачи с тремя пунктами завести один досрочно: «→ в бэклог» и «Сохранить» (см. 21.8)
2. Нажать ☑ на этой задаче — заводятся два оставшихся пункта
3. Развернуть бэклог и перетащить одну из двух новых задач в «Фокус»
4. В течение 7 секунд после ☑ нажать «Отменить»

**Ожидаемый результат:**
- Задача вернулась на прежнее место с прежним статусом
- Обе задачи, заведённые этим завершением, удалены с доски — и оставшаяся в бэклоге, и перетащенная в «Фокус»
- Два пункта снова не заведены, маркер `↪ 2` вернулся
- Пункт, заведённый раньше через «→ в бэклог», остался заведённым, его задача на месте

### 21.6 Перетаскивание в «Завершённые» и обратно

**Шаги:**
1. Перетащить задачу с незаведёнными пунктами в «Завершённые»
2. Переставить её внутри «Завершённых»
3. Вытащить её на доску и снова завершить

**Ожидаемый результат:**
- Шаг 1: то же, что в 21.4, но без toast'а отмены
- Шаг 2: ничего не заведено, уведомления нет
- Шаг 3: дублей нет, уведомления нет

### 21.7 Статус «Завершена» в форме

**Шаги:**
1. Открыть задачу с пунктами в рабочей группе, выбрать статус «Завершена», сохранить

**Ожидаемый результат:**
- Задача осталась в своей группе, ничего не заведено, уведомления нет, маркер на месте

### 21.8 «→ в бэклог»

**Шаги:**
1. Открыть задачу, у одного пункта нажать «→ в бэклог»
2. Закрыть форму через Escape и снова открыть
3. Снова нажать «→ в бэклог» у того же пункта и сохранить
4. В форме создания новой задачи заполнить «Что», добавить пункт, нажать у него «→ в бэклог» и сохранить

**Ожидаемый результат:**
- Помеченный пункт подсвечен, кнопка в нажатом состоянии; повторное нажатие снимает пометку
- После Escape ничего не создано, пункт не заведён, прочие правки формы тоже отброшены
- После сохранения в конце бэклога появилась одна задача и уведомление «…: 1», пункт отмечен «✓ заведено», маркер уменьшился на 1
- В форме создания заводятся и сама новая задача, и задача из пункта

### 21.9 Скрытый и переименованный бэклог

**Шаги:**
1. Переименовать бэклог в «Входящие» и скрыть его в настройках доски
2. Завершить задачу с пунктами

**Ожидаемый результат:**
- Уведомление «Заведено задач в «Входящие»: N (группа скрыта)»
- После показа бэклога заведённые задачи в нём

### 21.10 Форма задачи из «Завершённых»

**Шаги:**
1. Открыть завершённую задачу с пунктами, затем — завершённую задачу без пунктов

**Ожидаемый результат:**
- Пункты показаны текстом без полей ввода, без «→ в бэклог», ✕ и «+ Добавить пункт»
- У задачи без пунктов блока «После выполнения» нет

### 21.11 Темы оформления

**Шаги:**
1. Проверить блок «После выполнения», помеченный пункт и маркер в светлой и тёмной темах

**Ожидаемый результат:**
- Цвета берутся из темы, текст читается, помеченный пункт отличим от обычного
